Speed & Seamless Joining

  • Current chaining uses last-frame → first-frame + strong continuity language in every prompt. This is solid and already implemented in the generated workflow (duplicate first frames are trimmed, video + audio are concatenated).
  • For truly seamless motion & audio across many short clips, install ComfyUI-H3-Project-Suite or ComfyUI_MiniMax_H3_Extender and later swap the hand-off to latent / motion-context mode. The generator structure supports that upgrade.
  • Speed stack (recommended): keep SageAttention + EasyCache (already in the workflow) → add a Turbo LoRA (v4 / EMA preferred) → set Steps to 6–8. Community reports 3–5× wall-clock reduction with usable quality.
  • 4-second clips give tight narrative control (15 joins on a 60 s video) but increase the number of potential soft resets. 6–10 s is often a better continuity/speed compromise unless you specifically need rapid cuts.
  • Start image (I2V mode) must closely match the first segment’s character, clothing, environment and framing for best results.
