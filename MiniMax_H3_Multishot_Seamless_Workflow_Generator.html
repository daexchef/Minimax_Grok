MiniMax H3 Multishot Seamless

Builds Joey Gambino’s minimaxH330SecondSeamless_v13 graph. Fills the outer prompt and the subgraph slots Comfy still reads: H3ScriptSplit.script and H3MultishotMemorySampler.script.

1. Idea & length

3 shots × 10.0 s · 243 frames/shot (17n+5 @ 24 fps)

2. Planner (optional)

Local split writes one H3-style shot per box. LLM can write dialogue + camera + SFX per shot.

3. Models (your disk)

v13 ships INT4 CLIP + 8-step turbo LoRA. This page defaults to files you already have: qwen3vl_32b_minimax_h3_nvfp4_awq. Leave turbo off unless that LoRA file is in models/loras.

If turbo = No, the LoRA node is set to bypass (mode 4) so Comfy does not demand a missing file. Use ~12–20 steps. Turbo on: 8-step LoRA + ~8–12 steps.

4. Shots (these become all prompt slots)

Outer node gets {"prompts":[…]}. Inside the subgraph, the same texts are written as shot\n---\nshot on H3ScriptSplit and H3MultishotMemorySampler so leftover Arctic-hunter copy cannot win.

What this graph is

  • Not your clip-chain studio. One H3MultishotMemorySampler keeps a memory bank across shots.
  • CLIP lives on H3ClipLoaderAny inside the Image-to-Video subgraph — that is why it is easy to miss on the canvas.
  • Needs custom nodes: comfyui-h3-multishot, Spectrum MiniMax H3, FreeMemory, KJNodes (SageAttention).
  • After download: Load Image filename must match a file already in ComfyUI input/.
